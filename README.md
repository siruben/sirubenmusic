# Siruben Music

Leitor de música em néon com playlists, visualizador e modo Hilux. Funciona como app instalável (PWA) e abre sem internet.

As músicas ficam guardadas no próprio telemóvel (no browser), nunca saem de lá.

## Instalar
- Android (Chrome): menu ⋮ → Instalar app
- iPhone (Safari): Partilhar → Adicionar ao ecrã principal

## Atualizar
Depois de mudar o `index.html`, aumenta o número da versão em `sw.js` (`siruben-music-v1` → `v2`) para a app instalada se atualizar.
